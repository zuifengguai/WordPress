# WordPress新手入门教程第九节[小工具使用]



[b2_insert_post id="217"] WordPress 的小工具一般都是用于前台的侧栏和文章顶部的相关文章和随即文章之类。这个也跟所使用的主题有很大关系，部分完善的主题已经把这个小工具分为几个部分，上一节我们讲了**《第八节 WordPress 新手入门教程之插件使用篇》**今天我们将以知更鸟主题来讲解说明一下。

登录 WordPress 后台—>外观—>小工具，可以看到有很多选项设置，如下图所示：



![img](https://oss.zuike7.com/2022/05/20220515080506609.jpg)

知根鸟主题的小工具分为14个部分。至于其中作用应该很直白明了，**不再一一说明了。比如我们需要在正文（页面）侧栏跟随中添加一个最新文章，那么我们只需要把上图所示的“可用小工具”中的“主题 最新文章”左键拖动到正文（页面）侧栏跟随里面，然后放手即可。**这个“最新文章”默认的标题和显示数量都可以改动，改动后记得点击【保存】即可。

 

至于其他小工具的使用方法是一样的，直接拖动到相应位置放开，然后进行适当调整（上下拖动）和修改然后单击保存即可。在这里就不再一一说说大家可以慢慢折腾一番，这个还是比较容易掌握的。下一节，我们将讲解最后一个内容，就是**《第十节 WordPress 新手入门教程之友链管理篇》。**
