# WordPress新手入门教程第一节[准备工作篇]

## **WordPress建站前要准备的8件事**

## （就像开店前需要备齐营业执照、装修材料、店铺招牌一样）

**给网站起名字**

- 名字=你的品牌，建议先想好方向（比如美食分享/旅行日记）
- 名字最好和域名一致（例：网站叫「醉客网」，域名选[http://zuike7.com](https://link.zhihu.com/?target=http%3A//zuike7.com)）
- 提前查域名能不能注册（参考工具：阿里云/GoDaddy域名查询）

**买专属域名**

- 域名=门牌号（比如[http://taobao.com](https://link.zhihu.com/?target=http%3A//taobao.com)）
- 选短且好记的（优先.com/.cn，避开复杂拼音）
- 注册推荐：阿里云、腾讯云、Namecheap（国外）

**设计Logo和头像**

- Logo=店铺招牌，头像=社交账号形象
- 简单工具推荐：Canva（在线设计）、LogoMakr（免费生成）
- 注意：保持风格统一，建议用主色调不超过3种

**装好必备软件**

| 软件类型 | 推荐工具          | 作用说明                       |
| -------- | ----------------- | ------------------------------ |
| 本地环境 | WampServer/XAMPP  | 在电脑模拟服务器环境，测试网站 |
| 代码编辑 | Notepad++/VS Code | 修改主题代码、调整样式         |
| 文件传输 | FileZilla/WinSCP  | 把做好的网站传到线上服务器     |

**挑个好看的主题**

- 主题=店铺装修风格，新手建议选：
- 免费资源：WordPress官方主题库、Astra、GeneratePress
- 注意：选响应式设计（手机电脑都能看）+ 更新频率高的

**选网站服务器**

- 服务器=店铺的场地，建议：
- 新手选虚拟主机（价格低，操作简单）
- 国内需备案：阿里云/腾讯云（约300元/年）
- 免备案：香港/美国主机（例：SiteGround/Bluehost）

**域名备案（仅国内）**

- 流程：提交资料 → 服务器商初审 → 管局审核（约20天）
- 必备材料：身份证正反面、手机号、备案幕布照片
- 小技巧：工作日早上提交审核更快

**把域名指向服务器**

- 操作步骤（以阿里云为例）：
  ① 登录控制台 → 云解析DNS → 找到你的域名
  ② 添加两条记录：
  - 记录类型：A记录
  - 主机记录：填「@」和「www」
  - 记录值：填服务器IP（问主机商要）
    ③ 保存后等10分钟生效

### **一句话总结流程**

起名→买域名→做Logo→装软件→选主题→买服务器→备案→连域名
