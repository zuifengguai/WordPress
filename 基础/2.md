# WordPress新手入门教程第二节[上传安装篇]



[b2_insert_post id="76"]

上一节我们说了《第一节 WordPress 新手入门教程之准备工作篇》，在这一课上我们将重点说一下如何上传 WordPress 安装包到主机空间进行正确安装和能够正常访问网站。

 

1 、下载 WordPress 最新的安装包 我们可以直接在 WordPress 简体中文站点进行下载WordPress安装包。

官网下载：https://cn.wordpress.org/releases/

**本站资源下载**

[b2_insert_post id="53"]

2 、虚拟空间的需要通过 FTP 软件将安装包上传到主机FTP空间 **常见主机管理后台都支持在线解压缩，所以我们只需要将第一步下载的 WordPress安装包直接上传到主机空间即可。**如果主机不支持解压缩，那么就要先解压后将文件上传，这样的话就会上传很久，也很容易出错，所以买空间的时候还是**要考虑到有在线解压功能的主机**。

这里将以 flashfxp 和阿里云主机为例说明

[b2_insert_post id="35"]

 

2.1一般服务器安装通过宝塔将安装包上传服务器或者也用 FTP 将安装包上传到服务器；

服务器后台一般都支持在线解压缩，将下载的 WordPress安装包直接上传到服务器即可。

这里将以 腾讯云服务器和宝塔为例说明

![img](https://oss.zuike7.com/2022/05/20220511085815120.png)

1、 登录宝塔，打开打开宝塔后台，增加站点；并创建数据库；此处数据库的名称不用记住，在宝塔后台会看到数据库名称和密码；

![img](https://oss.zuike7.com/2022/05/20220511090051160.png)

2.删除增加的站点下的所有文件；

 

3、上传wordpress程序到宝塔网站根目录后解压wordpress程序；

 

4、将解压好的wordpress程序文件夹打开并剪切里面所有文件，复制到你网站根目录下面，删除wordpress压缩文件和wordpress文件夹； 

 

**[如果是服务器/VPN/宝塔/的话看上文操作,以下为虚拟空间]**

3.1 用 flashfxp 软件连接主机 打开flashfxp软件后点击导航栏的站点管理面板，接着点击新建站点，如下图：



![img](https://oss.zuike7.com/2022/05/20220511081500782.jpg)

设置框中的站点名称，站点名称我们就以wordpress为例，在**IP地址、用户名称、密码中输入购买主机所得到的 FTP 账号和密码**，然后点击【连接】即可连接到我们主机空间。

 

3.2上传wordpress程序到空间： 将我们刚才下载的 WordPress 安装包上传到 FTP 连接成功后空间中的 htdocs文件夹中，这里阿里云主机的根目录文件是htdocs，其它品牌的主机或许不是这个名字（其它的或许是web文件夹），打开htdocs文件夹后顺便把这个文件夹内的文件删除。 ![img](https://oss.zuike7.com/2022/05/20220511081643357.jpg)



我们只要将wordpress安装包托入到htdocs文件夹，然后点击右键传送例队后等待上传完，刷新就可以看到htdocs文件下有一个wordpress安装包了。

 

3.3在线解压安装包 安装包上传完后，下一步就要进入主机后台的控制面板进行在线解压程序安装包，进入主机后台后，点击左边的文件管理，在线解压缩： ![img](https://oss.zuike7.com/2022/05/20220511082035462.jpg)



解压缩文件：右边点击预览会看到我们上传的安装包，然后选择它。

解压后目录：选择预览，我们要选择站点根目录，提交。如下图 ![img](https://oss.zuike7.com/2022/05/20220511082209392.jpg)



解压完成后，我们回到flashfxp软件后刷新界面，我们会看到解压出来的文件夹wordpress，这时我们进入这个文件夹里面，全选所有文件，将全部文件移动到根目录 htdocs文件夹下面，这样所有的程文件就在根目录下面了，**移动完成功后删除wordpress这个空文件夹和原来的压缩包。**

 

3.4在线安装：

打开浏览器，在地址栏输入我们的网址地址，比如：http://baidu.com将会出现 WordPress 安装向导，点击【现在就开始】 ![img](https://oss.zuike7.com/2022/05/20220511082638946.jpg)



在出现的页面中，输入我们**输入****数据库的名称、用户名和密码，数据库主机默认即可**，**表前缀可默认，也可以将 wp 改为另外的字母（如xs_）**， 然后点击【提交】，最后在出现的页面中点击【进行安装】。如果出现安装不正确，就要考虑是否将数据库信息输错，这一点新手特别容易出错，如果数据库信息都是正确的，那么就要考虑php版本是否是wordpress所要求的php版本

 

**我建议php版本用 5.6/7.0/7.3。三个中任意版本**

 

 在出现的页面中，输入我们的站点标题（名称），站点管理员的用户名、密码（密码最好显示为强最好）、邮箱地址，然后点击【安装 WordPress】。**隐私的那个勾可以先去掉，也可以不管它**

 

如果出现成功，说明我们已经成功安装 WordPress，我们的站点已经可以访问了。点击【登录】就可以进入我们站点的后台。

到这里我们整个程序就上传完成了，下一节，我们将继续讲解《第三节 WordPress 新手入门教程之基本设置篇》。
